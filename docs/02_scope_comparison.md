# ความต่างระหว่างแนวเดิมกับแนวพลังงานบูรณาการ

วันที่ 10 พฤศจิกายน 2026

## ข้อสรุปสำหรับตัดสินใจ

แนวใหม่เพิ่มคำถามเรื่องคุณค่าของการใช้พลังงานหลายทางและการประสานระบบ มีโอกาสให้ข้อเสนอเชิงบริหารที่กว้างขึ้น แต่ต้องใช้ข้อมูล EV บริการโหลด รายได้และสิทธิ์มากขึ้น จึงควรเลือกว่าจะเปลี่ยนแกนวิทยานิพนธ์หรือทำเป็นส่วนขยายหลังพิสูจน์ฐานเดิม ไม่ควรนำทั้งสองแกนมารวมเป็นโจทย์ใหญ่โดยยังไม่มีเวลาหรือข้อมูลรองรับ

| ประเด็น | งานเดิมที่ตรวจจากเอกสาร | แนวใหม่ที่เสนอ |
|---|---|---|
| คำถามหลัก | ข้อมูล/แบบจำลองที่ถ่ายทอดเชื่อถือได้เพียงใดต่อการเลือกลงทุน | ควรลงทุนและจัดสรรพลังงานไปทางใดเมื่อเทคโนโลยีและมูลค่าทับซ้อนกัน |
| แกนหลัก v3 | Model calibration/transfer, uncertainty, investment reliability | Integrated planning, coordination value, service feasibility, cost–carbon trade-off |
| บทความเริ่มต้น 29 ต.ค. | ความละเอียดข้อมูลโหลดกับการจัดสรร PV | มูลค่าเพิ่มของ smart charging/flex/BESS/export ตามสิทธิ์ |
| PoC 2 พ.ย. | ระบบเดิม PV และ PV+BESS ที่ representative meter | เพิ่ม EV/flex แบบจำกัดก่อนขยายพอร์ต |
| คาร์บอน | ผลคาร์บอนของชุดลงทุนตาม boundary | เป้าลดคาร์บอนหลายระดับ residual และเส้นทาง Net Zero ที่ระบุ boundary |
| Export | เป็นข้อจำกัด/เงื่อนไขของ case | ศึกษาเป็นหนึ่งในทางใช้ไฟส่วนเกิน แยก eligibility กับ compensation |
| EV | ยังไม่เป็นแกน PoC เดิม | โหลดและบริการที่มีทั้งรายได้ ต้นทุนและ QoS |
| Flexible load | ประสิทธิภาพ/แบบจำลองอาคารตามข้อมูล | ตัดสินใจเวลาใช้งานภายใต้ service/comfort constraints |
| งานเพิ่ม | ไม่จำเป็นต้องมีทุกระบบ | ต้องมี EV arrival/departure, service targets, flexibility bounds, charging economics |
| ความใหม่ที่ต้องพิสูจน์ | reliability ของการตัดสินใจจาก model transfer | interaction/coordination value ภายใต้ topology, uncertainty และบัญชีไม่ซ้ำ |

## ส่วนที่ใช้ต่อได้โดยไม่แทนงานเดิม

ทะเบียนอาคาร ขอบเขตมิเตอร์ กติกาคุณภาพข้อมูล สมดุล PV/BESS แบบจำลองบิล และวิธีแบ่ง holdout สามารถนำแนวคิดมาใช้ต่อได้ แต่ต้องบันทึกที่มาและตรวจสมมติฐานใหม่ ไม่มีการคัดลอกผลตัวเลขเป็นข้อมูลจริงของแนวใหม่

## ส่วนที่ต้องออกแบบใหม่

- EV baseline และ same-service comparisons เพื่อแยกการเปิดบริการใหม่จากผลของ smart control
- ข้อจำกัดยืดหยุ่นของโหลดและ rebound/comfort
- บัญชีพลังงานร่วมเพื่อไม่ขาย ใช้เอง และเก็บไฟหน่วยเดียวซ้ำ
- ขอบเขตรายได้ว่าเป็นรายรับภายนอกหรือโอนภายใน
- cost–carbon frontier และ eligibility ของ renewable attributes/export
- fixed-design dispatch test ร่วมกับ planning test และ ablation

## ทางเลือกเชิงขอบเขต

**ทางเลือก ก คงแกนเดิมและเพิ่มกรณีทดลอง:** ใช้ EV/flex เป็นส่วนขยายที่มีข้อมูลจริง ข้อดีคือรักษาเส้นทางเดิมและภาระข้อมูลต่ำกว่า แต่คำถามเรื่องทั้งระบบจะตอบได้จำกัด

**ทางเลือก ข เปลี่ยนแกนเป็น integrated planning:** ใช้ร่างชุดนี้เป็นแนวหลัก ข้อดีคือสอดคล้องเป้าหมายใช้พลังงานให้เกิดประโยชน์หลายทาง ต้องทบทวน novelty ใหม่และยืนยันข้อมูลบริการก่อนลงทุนเวลาเต็มรูปแบบ

**ข้อเสนอเพื่อหารือ:** เริ่ม spike เชิงวิธีตามทางเลือก ข ที่มิเตอร์ตัวแทนหนึ่งจุด โดยมีจุดตัดสินใจข้อมูล 4–8 สัปดาห์ แล้วจึงเลือกว่าจะยกระดับหรือกลับเป็นส่วนขยายของแนวเดิม ตัวเลขระยะเวลาเป็นข้อเสนอ ไม่ใช่การเปลี่ยนกำหนดงานเดิม

## สิ่งที่คงไว้

Proposal v3, ร่างบทความ PV, developer handoff, tracker และไฟล์ iCloud เดิมไม่ได้ถูกแก้ ชื่อ CURRENT ในไฟล์เดิมยังไม่ได้ถูกย้ายมาที่แนวใหม่นี้ การมีเอกสารใหม่ไม่เท่ากับอาจารย์อนุมัติหรือถอนแนวเดิม
